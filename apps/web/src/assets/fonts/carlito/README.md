# Carlito

Unmodified Carlito Regular, Bold, Italic, and Bold Italic TrueType fonts from
Debian `fonts-crosextra-carlito` version `20230309-2`. See `copyright` for the
upstream SIL Open Font License and notices.

Source: https://deb.debian.org/debian/pool/main/f/fonts-crosextra-carlito/fonts-crosextra-carlito_20230309-2_all.deb

Package SHA-256: `1f86d76afaef81e19ce3b425dff6d9523ffb186f1f0fd9e40292e39d81c28147`.

These first-party assets load only for letter previews whose saved template
selects Carlito. No remote font service is used. This matches the font family
available in the isolated PDF converter; it is not an exact Avenir substitute.
